Archived after candle integrity audit.
Archive date: 2026-06-16

Critical fixes applied before this archive boundary:
- Timestamp alignment: candle 'time' now uses open time (t) not close time (T)
- HTF regime look-ahead removal: _compute_htf_regime now drops forming 1H candle and last 4H bar
- Macro regime contamination removal: _compute_macro_regime_4h drops forming 1H candle and current incomplete day
- Daily zone contamination removal: _compute_daily_zone drops forming 1H candle and current incomplete day's high/low
- Swing signal contamination removal: generate_swing_signal drops forming 1H candle before resample
- Backtest timestamp fix: analyze_winrate.py and backtest_missed.py use open time (t), not close time (T)

Do NOT combine archived performance metrics with post-fix metrics.

All data in this directory was collected under the pre-fix code and is
considered a separate research dataset. The regime classifications, daily zone
scores, HTF trend readings, and VWAP anchors in this data were computed using
partially formed bars. Performance statistics (win rate, R, profit factor)
derived from this data are not valid benchmarks for the post-fix system.
